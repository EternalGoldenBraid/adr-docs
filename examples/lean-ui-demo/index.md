# Warehouse robot navigation

A synthetic demo site for ADR design work. Nothing here is real.

- [Route costs](/planning/route-costs): how the planner prices a path.
- [Battery policy](/planning/battery): when a robot must return to charge.
- [Fleet operations](/ops/fleet): shifts, aisles and the handover checklist.

The goal is a fleet of twelve robots that moves 400 pallets per shift without blocking an aisle for more than ten seconds.
