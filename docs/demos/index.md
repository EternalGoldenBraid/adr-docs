# Agent Doc Review demos

Short recordings of the main features, generated by `npm run demos`
(`tools/record_demos.mjs`). Re-record after a release so they stay true.

## Select text and comment

<video controls src="/select-and-comment.webm"></video>

Select text, press `c`, write, send. The highlight stays; `-h` lists threads.

## Command line and help

<video controls src="/command-line-help.webm"></video>

`:` opens the command line; `:help` lists every key and command.

## Links between comments

<video controls src="/comment-links.webm"></video>

A thread links to related threads (`→`) and shows backlinks (`←`). Following a
link opens the target, on another page if needed.

## Triage threads from the keyboard

<video controls src="/thread-triage.webm"></video>

In the thread list `j`/`k` move, `l` opens, `r` resolves and moves to the next
thread, `[`/`]` switch tabs, `h` goes back and `Esc` closes.

Preview this page with
`npm run preview -- docs/demos/index.md`.
